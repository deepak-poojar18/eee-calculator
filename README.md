# EEE Calculator

A Python calculator for basic electrical engineering calculations.

## Features
- Calculate voltage using Ohm's law.
- Calculate resistance using Ohm's law.
- Calculate current using Ohm's law.
- Calculate electrical power.
- Validate user inputs.

## Requirements
- Python 3

## How to Run
Run the calculator:

    python calc.py

Run the tests:

    python test.py

## Formulas
- Voltage: V = I × R
- Resistance: R = V / I
- Current: I = V / R
- Power: P = V × I

## Purpose
A beginner Python project applying basic electrical engineering concepts.
